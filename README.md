# Raft browser

Spelling rafts for Hindi words written in Latin script, and the rules that build them. Open the page:
https://readysetdive.github.io/raft-browser/

Built from counts derived from:
- hinglishNorm (Makhija et al., 2020), https://github.com/piyushmakhija5/hinglishNorm
- Dakshina dataset (Roark et al., 2020), https://github.com/google-research-datasets/dakshina, CC BY-SA 4.0
- SentiMix, SemEval-2020 Task 9 (Patwa et al., 2020)

No sentences or tweets are included, only per-word counts.
